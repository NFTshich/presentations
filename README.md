# Презентации

Набор готовых презентаций (PPTX) для бизнеса. Настраиваются под ваши цифры и тексты.

## Примеры

- `квартальный-отчёт-демо.pptx` — отчёт для руководства за квартал:
  ключевые цифры, динамика, структура выручки, проблемные позиции, риски, план.
  Демонстрационные данные (10 слайдов, готово к замене на ваши).

## Как использовать

1. Откройте `.pptx` в PowerPoint (или Google Slides).
2. Замените тексты, цифры и графику на свои.
3. Экспортируйте в PDF для рассылки.

Файлы редактируемые, с аккуратной вёрсткой.
